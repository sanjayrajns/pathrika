# 📰 Pathrika - News Web App

**Pathrika** is a modern news website built with **HTML**, **CSS**, and **JavaScript** that delivers real-time news fetched from the [NewsAPI](https://newsapi.org). It features category filtering, responsive design, and a search bar for topic-based browsing.
---

## ✨ Features

- ✅ Real-time news using [NewsAPI](https://newsapi.org)
- ✅ Category tabs (National, International, Politics, Finance, Science, Technology)
- ✅ Search functionality for news topics
- ✅ Responsive layout (mobile & desktop-friendly)
- ✅ Clean UI and fast performance

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- Vanilla JavaScript  
- NewsAPI

---

## 🧪 How to Run Locally

1. Clone the repo:
   ```bash
   git clone https://github.com/yourusername/pathrika-news-app.git
   cd pathrika-news-app
   ```

2. Open `index.html` in your browser.

3. Replace the placeholder API key in the JS file with your actual [NewsAPI](https://newsapi.org) key:
   ```js
   const apiKey = "YOUR_API_KEY_HERE";
   ```
